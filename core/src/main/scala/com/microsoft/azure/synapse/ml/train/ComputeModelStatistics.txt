``ComputeModelStatistics`` returns the specified statistics on all the
models specified

The possible metrics are:

Binary Classifiers:

- "areaUnderROC" (reported in the "AUC" column)
- "AUC"
- "areaUnderPR"
- "accuracy"
- "precision"
- "recall"
- "classification"
- "all"

Regression Models:

- "mse"
- "rmse"
- "r2"
- "mae"
- "regression"
- "all"
